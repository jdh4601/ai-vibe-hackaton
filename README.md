# 새내기 오디세이: 나의 학과를 찾아서 (가제)

> AI로 다시 쓰는 대학생활 해커톤 출품작

인천대 자유전공학부 27학번 새내기가 학교 광장을 돌아다니며 학과 선배들의 과제를 도와주고, 학과 스킬을 도감에 모은 뒤, 마지막에 자신의 전공을 골라 그 학과의 과잠을 받는 3인칭 3D 웹 오픈월드 게임입니다.

## 왜 만드나요?

자유전공학부 학생은 1학년 동안 전공을 골라야 하지만, 학과에서 실제로 무엇을 하는지 체험할 기회가 거의 없습니다. 이 게임은 각 학과에서 실제로 배우는 내용을 쉬운 미니게임으로 바꿔서, 몇 분 만에 "해 보니 재밌다/아니다"를 느끼게 합니다.

## 게임 흐름

1. **오프닝**: 잠에서 깨어나 합격 문자를 열면 "인천대학교 자유전공학부 27학번" 합격 통지서가 나타납니다.
2. **광장 탐색**: 12호관 앞 광장을 모티브로 한 맵에서 학과 NPC 20명을 만납니다. 가까이 가면 학과 고증 말풍선이 뜹니다.
3. **학과 퀘스트**: 대화 → 학과 소개 → "도와줄래?" → 드래그 위주의 미니게임 → 스킬 획득
4. **돌발상황**: 교수님의 대학원 납치, 동기의 과제 통보, 간식 나눔 행사
5. **엔딩**: 체험한 학과 중 하나를 전공으로 고르면, 선배가 그 학과의 과잠을 입혀 줍니다.

## 퀘스트 학과

| 학과 | 미니게임 | 스킬 |
|---|---|---|
| 전자공학부 (임베디드) | 다이얼을 돌려 전압 맞추기 | 📡 라이다 센서: 거리두기 능력 |
| 디자인학부 (제품디자인) | 컵 평면도 따라 그리기 | 🎨 고흐의 미감 |
| 수학과 | 수열 빈칸 채우기 | 📐 피타고라스의 각도기 |
| 동북아국제통상학부 | 중국어 문장 순서 맞추기 | 🇨🇳 제갈량의 지략 |
| 컴퓨터공학부 | 코드 블록 정렬로 서버 살리기 | 🐧 리누스 토르발스의 손가락 |
