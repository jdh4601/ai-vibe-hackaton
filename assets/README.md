`characters/hero/hero-front-v2.png`, `hero-back-v2.png`, `hero-left-v2.png`, `hero-right-v2.png`

- 좌우는 캐릭터 착용자 기준이다.
- 학교 로고, 소매 문양, 가방을 제거했다.

- PNG 참고 이미지이며 실제 3D 메시나 리깅 파일은 아니다.
- 생성 프롬프트: `characters/hero/hero-views-v2-prompts.json`

## 광장 — 사용자가 제공한 원본 레퍼런스

- `references/plaza/plaza-01.jpg`: 광장 사진 1. 넓은 전경, 바다, 건물, 잔디, 산책로, 계단 캐노피, 물결 조형물 확인용.
- `references/plaza/plaza-02.jpeg`: 광장 사진 2. 다른 각도에서 본 건물, 잔디, 보행로, 식재 배치 확인용.

두 사진을 함께 광장 구현 레퍼런스로 사용한다. 원본을 재압축하지 않고 복사했다. 사진에서 확인되지 않는 치수와 가려진 구조는 확정된 사실로 취급하지 않는다.
